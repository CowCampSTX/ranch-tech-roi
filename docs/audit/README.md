# audit

The plan and the spec, which every change is built and reviewed against (see AGENTS.md, "The plan is the spec").

- `phase1-spec.md`: the phase-1 specification (section 9), the validation plan (section 10) and Appendix A, the
  pinned results of the four synthetic example ranches
- `ranch-tech-roi-audit.md`: the audit (sections 1 to 7), the roadmap (section 8), the synthetic examples
  (section 11) and the owner's decisions and open items (section 12)
- `evidence-table.md` and `evidence-table.csv`: the evidence table (section 5.3); the CSV has full source URLs
- `sources.md`: the source list (section 13)
- `prototype/`: a script that reproduces Appendix A, a reference for the numbers

Section numbers run across the files. Changes to the plan go here, dated in the text.
