# Docs

Everything about Ranch Tech ROI beyond the code. GitHub is the source of truth; Google Drive holds readable copies in
the same folders (My Drive > `Ranch Tech ROI`). Change a file here first, then refresh the Drive copy.

| Folder | What is in it | Drive |
| --- | --- | --- |
| [`audit/`](audit/) | The plan and the spec: the audit and roadmap (`ranch-tech-roi-audit.md`), the phase-1 specification (`phase1-spec.md`), the evidence table (`.md` and `.csv`), the source list (`sources.md`) and the prototype that reproduces Appendix A (`prototype/`) | `Ranch Tech ROI/audit` |
| [`images/`](images/) | The screenshots in the main README | `Ranch Tech ROI/images` |
| [`training/`](training/) | The training path: `outline.md`, the slide deck's source (`deck/`) and the screenshots it uses (`shots/`). The deck is published at https://claude.ai/artifact/ANXUwkPPZ95YDk4F9W7JTn | `Ranch Tech ROI/training` |
| [`archive/`](archive/) | Dated material kept for the record, not for building against: the 14 Oct 2026 handoff note and screenshots of the version 1 page | `Ranch Tech ROI/archive` |

Adding material: put it in the folder it belongs to. Add a new folder (here and in Drive, and a row above) only for a
new kind of material. Name dated material `YYYY-MM-DD-what`. Every folder has a `README.md` saying what belongs in it. Instructions for AI agents are in
[`../AGENTS.md`](../AGENTS.md).
