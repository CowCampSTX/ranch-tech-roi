# training

The training path for using and pitching the calculator.

- `outline.md`: the outline the deck is built from, with the numbers read off the live page
- `deck/`: the slide deck's source; the deck is published at https://claude.ai/artifact/ANXUwkPPZ95YDk4F9W7JTn
- `shots/`: the screenshots the deck uses, numbered in slide order
