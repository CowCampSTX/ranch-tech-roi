# Training deck source

The source of the published slide deck (https://claude.ai/artifact/ANXUwkPPZ95YDk4F9W7JTn): `deck.json` sets the
slide order and sections, and `slides/` has one HTML file per slide. Images in the slides point at the deck's asset
store (`/_blob/...`); the same screenshots are in [`../shots/`](../shots/). To change the deck, edit these files and
republish the artifact from them.
